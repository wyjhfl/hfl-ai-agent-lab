# 项目 B 路线图

项目 B 采用版本迭代方式推进，每个版本都有明确边界。

## v0.1：基础 Copilot 链路

目标：

- 用户输入自然语言需求
- 系统识别意图
- 返回结构化任务计划
- 完成最小可运行链路

## v0.2：NL2SQL 与 Schema 剪枝

目标：

- 接入数据库 Schema
- 根据问题筛选相关表
- 生成 SQL
- 返回查询结果和解释

## v0.3：多工具编排

目标：

- 引入多个业务工具
- 支持工具注册
- 支持工具选择
- 支持执行结果追踪

## v0.4：Human-in-the-loop 审批

目标：

- 识别高风险操作
- 暂停执行流程
- 等待人工确认
- 根据确认结果继续或终止流程

## v0.5：Trace / Evaluator / Reflection

目标：

- 记录 Agent 执行轨迹
- 对结果进行质量检查
- 识别失败原因
- 输出改进建议

## v1.0：求职展示版本

目标：

- 完整演示链路
- 项目文档完善
- 架构图完善
- README 完善
- 面试表达完善
