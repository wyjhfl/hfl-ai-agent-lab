## 项目 A：设备售后诊断与工单 RAG 系统

面向设备售后场景，构建智能诊断与工单管理系统。

核心能力：

- RAG 知识库：基于向量数据库的设备故障知识检索
- 故障诊断：结合 RAG 的智能问答与故障分析
- 工单生成：将诊断结果自动转化为可追踪工单
- 后端工程化：FastAPI + 数据库 + Docker 部署
