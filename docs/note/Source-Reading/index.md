# Agent 源码拆解

这里用于沉淀 AI Agent / Multi-Agent 项目的源码阅读、架构分析和可迁移设计。

这个模块不是单纯记录源码细节，而是把源码拆成三层：

1. 项目解决什么问题
2. 架构如何组织
3. 哪些设计可以迁移到自己的项目中

## 拆解对象

当前先整理三个方向：

- Hermes Agent
- Harness Engineering
- OpenClaw

## 统一拆解模板

每个项目都按照以下结构整理：

1. 项目定位
2. 核心架构
3. 运行链路
4. 关键模块
5. 工程亮点
6. 可迁移设计
7. 面试表达

## 学习目标

源码拆解的目标不是背代码，而是形成自己的 Agent 工程判断能力：

- 看懂一个 Agent 项目的模块边界
- 看懂任务是如何流转的
- 看懂工具调用是如何组织的
- 看懂状态是如何维护的
- 看懂结果是如何评估和反馈的
