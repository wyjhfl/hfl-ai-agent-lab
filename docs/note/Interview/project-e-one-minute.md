# Project E 一分钟介绍

## 面试开场版

Project E 是一个 AI Coding Agent Workbench，用来把 Codex、Claude Code、Copilot 或自研代码 Agent 接入团队软件工程流程。它不是简单让模型写代码，而是覆盖任务理解、上下文打包、代码执行、测试验证、代码审查、PR 描述、失败回放和 Skill 沉淀。

我设计这个项目的原因是：AI 编程工具真正进入团队后，大家关心的不是“能不能生成代码”，而是改动是否在范围内、测试是否真实跑过、PR 是否可审查、失败能不能复现、好的流程能不能复用。

这个项目展示的是 AI Coding Agent 工程化能力：Context Engineering、Verification Gate、Code Review Bench、Repo Automation Console 和 Skill Library。

## 30 秒压缩版

Project E 是一个代码代理工作台，把 issue 转成 task brief，把仓库相关文件打成 context pack，让 Agent 执行改动，再通过测试门禁、代码审查、PR 描述和失败回放完成交付。它证明我会把 AI Coding Agent 接入真实工程流程。

## 简历 bullet

- 设计 AI Coding Agent Workbench，将任务理解、上下文打包、代码修改、测试验证、代码审查和 PR 交付串成可审计流程。
- 构建 Code Review Bench，评估代码代理在 correctness、scope control、security、verification honesty 和 maintainability 上的质量。
- 设计 Repo Automation Console UI，展示 task brief、context pack、verification gate、review findings 和 PR evidence。
