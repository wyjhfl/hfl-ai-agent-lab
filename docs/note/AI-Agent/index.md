# AI Agent 学习路线

这里是 HFL AI Agent Lab 的核心知识路线，用于系统沉淀 AI Agent、Multi-Agent、LangGraph、RAG 和 LLM 应用工程能力。

## 学习主线

1. LLM 应用基础
2. Prompt Engineering
3. RAG 基础与工程化
4. Tool Calling / Function Calling
5. Agent Loop
6. Planning / Memory / Reflection
7. LangGraph 状态机
8. Multi-Agent 架构
9. Human-in-the-loop
10. Trace / Evaluation
11. Production Engineering

## 学习目标

这个知识库不是为了记录零散概念，而是为了服务一个目标：

> 能够设计、实现、解释一个可控、可审计、可扩展的 AI Agent 工程系统。

## 对应项目

当前主线项目是：

- 项目 A：设备售后诊断与工单 RAG 系统
- 项目 B：运营中台多 Agent Copilot
