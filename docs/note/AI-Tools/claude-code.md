# Claude Code 拆解

## 当前定位

Claude Code 是 Anthropic 推出的 CLI 工具，适合仓库级修改、批量文件重构、文档整理、构建检查和 Git 提交流程。

在这个项目中，Claude Code 被用作版本迭代的执行工具：ChatGPT 负责规划和生成提示词，Claude Code 负责在仓库中实际执行修改。

## 核心能力

### 读取项目结构

Claude Code 可以读取目录结构、搜索文件、查看文件内容，快速理解项目布局。这让它能够在修改前了解上下文，而不是盲目操作。

### 按提示修改多个文件

Claude Code 可以在一个会话中修改多个文件，保持上下文一致。这对于需要跨文件同步修改的场景（如统一术语、调整结构）非常有用。

### 保持上下文一致

Claude Code 在会话中维护上下文，前一步的修改结果会影响后续决策。这让多步修改能够保持一致性，不会出现前后矛盾的情况。

### 执行构建命令

Claude Code 可以执行 shell 命令，包括构建、测试、lint 检查。这让它能够在修改后立即验证结果，而不是等到手动构建时才发现问题。

### 输出修改总结

每次修改后，Claude Code 会输出修改总结，说明改了什么、为什么改。这让人工审查变得更容易。

### 配合 Git 提交

Claude Code 可以执行 git add、git commit、git push，完成从修改到提交的完整流程。

## 适合做什么

- 文档站结构调整
- README 优化
- 多文件内容同步
- 构建错误修复
- 版本迭代执行
- 批量术语替换
- 侧边栏和导航配置修改

## 不适合做什么

- 不了解业务背景时直接设计复杂项目
- 未给出明确边界时大规模重构
- 凭空编造不存在的源码细节
- 替代人工审查
- 需要运行时调试的场景
- 需要访问外部认证服务的场景

## 和 ChatGPT 的配合方式

推荐的工作流是：

1. ChatGPT 负责规划：制定版本目标、分析修改范围、生成 Claude Code 提示词
2. Claude Code 负责执行：在仓库中修改文件、运行构建、提交代码
3. ChatGPT 负责审查：检查修改结果、提出调整建议、规划下一版本

这种分工让每个工具做自己擅长的事：ChatGPT 擅长规划和审查，Claude Code 擅长仓库级执行。

## 使用经验

### 提示词要明确边界

给 Claude Code 的提示词应该明确说明：修改哪些文件、不修改什么、验收标准是什么。边界越清晰，输出质量越高。

### 每次修改后构建检查

Claude Code 修改文件后应该运行构建命令，确保没有引入错误。这比等到最后一次性构建更可靠。

### 版本迭代而非一次性大改

把大任务拆成多个小版本，每个版本有明确目标。这让每次修改都可控可审查。
