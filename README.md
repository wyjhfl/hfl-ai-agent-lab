# HFL AI Agent Lab

AI Agent 工程知识库 · 多 Agent 项目展示 · 求职作品集

## 项目定位

这是我的个人技术知识库和项目展示站，主要用于沉淀 AI Agent、Multi-Agent、LangGraph、RAG、LLM 应用工程和后端工程化相关内容。

## 本地开发

```bash
npm install
npm run docs:dev
```

```bash
npm run docs:build
npm run docs:preview
```
